Regard tient d’abord dans deux questions.

> **Qu’est-ce qui compte ici ?**

La table précise ce qu’elle regarde avec un **Focus** et à quelle échelle avec un **Zoom**.

Elle cherche ensuite les éléments qui comptent réellement pour cette question. Ils peuvent venir de la scène, du personnage, de sa feuille, de ses relations, de sa mémoire, de son passé, du lore, du monde ou de ce qu’il anticipe de l’avenir.

Les éléments retenus deviennent des **Mises**.

> **Une Mise est un élément reconnu comme pertinent pour le Focus, à ce Zoom.**

Une Mise n’est pas un bonus automatique. Un élément peut être important pour le personnage et ne rien apporter ici. À l’inverse, un détail qui n’apparaît sur aucune feuille peut devenir décisif.

Le Focus détermine aussi de quel côté une Mise pèse.

La seconde question est :

> **Comment cette manière d’habiter le monde transforme-t-elle l’incertitude ?**

C’est le rôle du **Prisme**.

Dans la configuration standard, le Prisme est volontairement discret : chaque Mise apporte un D6, un résultat pair produit une Réussite, puis les Réussites des deux issues sont comparées.

Cette configuration est complète et directement jouable.

Mais elle n’est pas la seule forme possible de Regard. Un jeu peut modifier le support, la lecture de l’incertitude, la forme du résultat, la manière dont plusieurs perspectives agissent ensemble, ou même employer un Prisme qui produit un résultat autonome.

Le reste des règles sert surtout à garder ce geste cohérent :

- l’**Intention** dit ce que le personnage cherche à obtenir ;
- le **Focus** isole ce qui reste à décider ;
- le **Zoom** choisit l’échelle ;
- les conséquences importantes sont annoncées lorsqu’elles doivent l’être ;
- les **Facteurs Cadres** ferment les possibilités que le monde ou la situation ne permettent pas ;
- la non-redondance évite de compter plusieurs fois la même raison ;
- l’interprétation ramène le résultat dans la fiction.

Ce qui arrive peut ensuite transformer durablement le personnage, ses relations, son monde et donc **ce qui pourra compter plus tard**.

> **Regard apprend à regarder ce qui compte, puis laisse le monde répondre à travers l’incertitude.**
